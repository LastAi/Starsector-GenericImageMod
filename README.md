# Generic Image Mod

A library of generic illustrations for **Starsector 0.98a** mods: bars and galas, derelicts and
salvage work, markets and landing pads, stations, colonies in dust storms and ice, creatures, and
more (51 pictures). It adds no content of its own; mods that use its pictures list it as required.

## For players

Install it when a mod needs it: unzip (or copy this folder) into `Starsector/mods/` and enable it in
the launcher. It only registers pictures, so it is safe to add to or remove from a save.

## For modders

Every picture is registered in `data/config/settings.json` under `graphics.illustrations`, with
keys starting `gim_` (for example `gim_gala`, `gim_bar_1`, `gim_derelict_1`). Like vanilla's
illustration keys they are global: with this mod enabled, any mod can show one, e.g. with
`ShowImageVisual gim_gala` in rules.csv. List Generic Image Mod as a required mod (its id is
`generic_image_mod`).

In **[Saga Forge](https://github.com/LastAi/Starsector-SagaForge)**: once this mod is in your
workspace (or `Starsector/mods/`), its pictures show up in every "Choose…" picture picker, and the
export lists it as a dependency. The `sagaforge/` folder is its Saga Forge project, so you can open
it, add your own pictures and export.

## AI use disclaimer

Some or all assets in this mod were created using AI tools:

- **Art**: every picture was generated by the author with AI image tools, then picked, cropped and
  resized in Saga Forge.
- **Text / Code**: none (it only registers pictures).
